# Elas Livres

Aplicação web voltada à orientação e ao acesso a oportunidades de emprego e informações de proteção.

## Funcionalidades

- Página inicial com acesso às áreas principais.
- Pesquisa de oportunidades por palavra-chave e modalidade.
- Área de proteção com orientações e serviços de apoio.

## Tecnologias

- Frontend: Angular e TypeScript.
- API: Python.
- Banco de dados: PostgreSQL.

## Organização do código

- `frontend/` — interface web.
- `backend/` — API.
- `database/` — estrutura de persistência.
- `docs/` — documentação técnica.

## Configuração de desenvolvimento

Pré-requisitos: Node.js, npm, Python 3 e PostgreSQL.

A estrutura inicial está organizada. Os comandos de instalação e execução específicos de cada aplicação serão adicionados aos respectivos diretórios quando os módulos forem implementados.

## Segurança

Não inclua arquivos `.env`, credenciais, dados pessoais ou arquivos de banco de dados no versionamento.
